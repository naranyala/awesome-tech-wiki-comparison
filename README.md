## Contributing

Add an entry only when it links to a Wikipedia article whose main subject is a comparison of technology or software products, services, platforms, hardware, or standards. Keep entries in the most relevant section, use the article's exact title and canonical Wikipedia URL, and avoid general comparisons that only mention technology. This list is meant to be software-heavy and technically focused, so prefer articles that compare implementation choices, platforms, runtimes, stacks, tools, and systems rather than broad consumer categories.
